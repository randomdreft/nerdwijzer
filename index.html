📐 Hoe wordt de score berekend?

Basis formule per vraag:

  • Afstand = |jouw_antwoord - partij_antwoord| (0-4)
  • Match percentage = max(0, 100 - (afstand × 25))
  • Afstand 0 = 100% match, afstand 1 = 75%, afstand 2 = 50%, afstand 3 = 25%, afstand 4 = 0%

Gewichting:

  • Standaard vragen: gewicht 1x
  • Belangrijke vragen (die je selecteerde): gewicht 3x
  • Digitale vragen (als je digitale zaken "heel belangrijk" vindt): extra gewicht 1.5x

Eindscore berekening:

  • Gewogen gemiddelde = (totaal_match_score × gewicht) / totaal_gewicht
  • Digitale bonus = (digitale_score / 15) × 100 × 0.2 (max 20%)
  • Eindscore = min(100, gewogen_gemiddelde + digitale_bonus)

Voorbeeld: Jij geeft 3, partij geeft 4 → afstand 1 → 75% match. Als dit een belangrijke digitale vraag is: gewicht = 3 × 1.5 = 4.5x
